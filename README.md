# مساعد القدرات

تطبيق ويب للتدرّب على أسئلة اختبار القدرات، مع شرح بالذكاء الاصطناعي (Gemini).

## ⚠️ ملاحظة أمنية مهمة
المفاتيح القديمة التي كانت مكتوبة داخل `index.html` تُعدّ **مسرّبة** ويجب إلغاؤها فوراً
من Google AI Studio / Google Cloud Console. لا تضع أي مفتاح API في كود المتصفح إطلاقاً.

## كيف يعمل إخفاء المفتاح
- المتصفح (`index.html`) لا يحتوي على أي مفتاح. هو فقط ينادي المسار `/api/explain`.
- خادم `server.js` يحتفظ بالمفتاح في متغير بيئة (`GEMINI_API_KEY`) ويتواصل مع Google نيابةً عن المتصفح.
- المفتاح يبقى على الخادم ولا يصل المستخدم النهائي أبداً.

## التشغيل محلياً
```bash
npm install
cp .env.example .env      # ثم ضع مفتاحك داخل .env
npm start
```
افتح: http://localhost:3000

## الملفات
- `index.html` — الواجهة.
- `questions.js` — بيانات الأسئلة (يجب أن يعرّف `verbalAnalogyQuestions` و`engineeringQuestions`).
- `server.js` — الخادم الوسيط الذي يخفي المفتاح.
- `.env` — مفتاحك (غير مرفوع إلى Git).
